# ExerciseAbstraction

A Java practice repository focused on abstraction in object-oriented programming.

## Project Overview

This repository is used to practice hiding implementation details and exposing only the important behavior through abstract classes or methods.

## Main Topics

- Java fundamentals
- Object-Oriented Programming
- Abstraction
- Abstract classes
- Abstract methods
- Code organization

## Learning Goals

- Understand the purpose of abstraction.
- Practice creating abstract classes.
- Define shared behavior for related classes.
- Improve code structure and readability.
- Build a stronger OOP foundation.
